## 🔄 PASO 3: CONVERTIR HTML A GOOGLE DOCS

**IMPORTANTE:** Google Drive puede convertir HTML automáticamente a Google Docs cuando los abres.

### Método 1: Conversión al abrir

1. En Google Drive, **toca uno de los archivos HTML** que subiste

2. Se abrirá en el visor de Google Drive

3. Toca el **menú (tres puntos)** arriba a la derecha

4. Selecciona **Abrir con → Google Docs**

5. Google Docs abrirá el archivo y lo convertirá automáticamente

6. Para guardarlo como Google Doc:
   - Toca **menú (tres puntos)**
   - Selecciona **Crear una copia**
   - La copia se guardará como Google Doc nativo

7. **Repite para los otros 3 archivos HTML**

### Método 2: Conversión desde computadora (si tienes acceso)

Si tienes acceso a una computadora:

1. Ve a https://drive.google.com

2. Abre la carpeta `CCA_NEXUS_CONVERSACIONES_RECONSTRUIDAS_20260531`

3. Para cada archivo HTML:
   - Click derecho en el archivo
   - Selecciona **Abrir con → Google Docs**
   - Google Docs lo abrirá y convertirá
   - Archivo → Guardar como Google Docs (si no se convirtió automáticamente)

### "No puedo subir archivos"
- Verifica que tengas espacio en Google Drive
- Intenta subir un archivo a la vez
- Verifica tu conexión a internet

### "El HTML se ve mal al abrir"
- Eso es normal, por eso lo convertimos a Google Docs
- Sigue el PASO 3 para convertirlo

### "Google Docs no conserva el formato"
- El contenido SÍ se preserva (que es lo importante)
- El formato visual puede cambiar ligeramente
- Todo el texto está intacto

### "No veo la opción 'Abrir con Google Docs'"
- Intenta desde la computadora en lugar del celular
- O simplemente abre el HTML en Google Drive y cópialo manualmente a un nuevo Google Doc
